# 长期记忆优化验收（2026-10-05）

## 结论

保留 MySQL 真相源 + Mem0 候选抽取 + 派生索引，不迁移图数据库。
已交付批量校验、实时有效期过滤、持久重试与对账、轻量偏好版本、语义缓存和降级、候选 TTL、API 托管 worker。
不以向量相似度直接判定事实等价；非结构化同义去重未自动化，避免吞掉数字/否定变化。

## 验证范围

- 全量后端 284 项通过；孤儿清理保护追加相关 8 项通过。
- 真实 MySQL/Chroma/Embedding/Mem0 候选抽取测试通过：CRUD、幂等、更新、缺失修复、删除、revision 冲突、候选清理。
- 真实测试使用独立租户、随机集合，仅清除自建数据；没有删除现有用户数据。
- 非致命依赖提示：jieba regex 警告、Chroma telemetry 兼容警告、Mem0 的 Chroma 不支持 BM25/spaCy 未安装。未宣称 Mem0 自带混合检索已启用。

## 小样本质量结果

固定开发者编写数据：8 条记忆，dev/test 各 6 个正例 + 2 个无关问题。
数据 SHA256：`12e487fb30cd40c266a8058eb75726edd52f34171e4e1e6dfe9dd23c227e87e6`。
Embedding 为当前配置的 text-embedding-v3 / 1024 维；阈值 0.5。

| 测试集指标 | 旧词面+confidence | 新本地分词 | 缓存语义排序 |
|---|---:|---:|---:|
| 正例 Hit@1（6 个） | 1/6 | 1/6 | 6/6 |
| 无关问题注入数（2 个） | 2/2 | 0/2 | 0/2 |

重复测试结果一致，但这不是生产准确率、完整 Mem0 链路或用户日志评测。
开发集新分词 6/6、语义排序 5/6，说明语义路径不是所有表达都更好，公共默认仍为关闭；本地作为演示启用。
旧实现基线是 `_memory_score` 排序；不是原先 Mem0 语义主路径。因此不能写成“整个记忆系统从 16.7% 提升到 100%”。

固定危险去重用例：4 类变化误合并从 4/4 降到 0/4；同义漏合并仍有 2 对。
批量校验一次 SELECT 的收益由查询计数测试确认，未把它换算成未经测量的线上延迟提升。

## 组件减法实验

仅比较预计算向量下的纯 Python cosine 排序与 Chroma HTTP query，不含 MySQL、embedding、权限校验、完整请求。
200 条规模由 8 条向量重复生成，只用于观察计算/调用开销，不代表 200 条独立真实记忆的质量。
每种规模每轮 40 个样本，两轮观测：

| 规模 | Python P50 / P95（毫秒） | Chroma P50 / P95（毫秒） |
|---|---|---|
| 8 条，第一轮 | 0.67 / 1.31 | 22.39 / 31.65 |
| 200 条，第一轮 | 14.02 / 18.44 | 23.08 / 28.62 |
| 8 条，复测 | 1.94 / 2.80 | 31.23 / 37.29 |
| 200 条，复测 | 39.41 / 68.99 | 32.09 / 47.88 |

小规模本地排序有潜力，但 200 条纯 Python 排序并非稳定更快，不足以支持立即拆除 Chroma。
第一轮与全量测试存在并行负载；复测未同时运行本次 pytest，但不控制其他系统负载，不做显著性/线上 SLA 结论。
一次批量 embedding 观测约 1.90–4.88 秒，冷缓存不能忽略。缓存只在进程内，重启会变冷，候选读取上限 200 不是每用户存储上限。

## 运行与回滚

本地已启用 `MEMORY_SYNC_ENABLED=true`、`MEMORY_SEMANTIC_FALLBACK=true`、阈值 0.5。
重启 API 后自动启动 worker；不要再同时运行独立 `--watch`。持久队列支持重试，运行时仍需监控 pending/attempts/错误日志。
回滚语义排序只需关闭 MEMORY_SEMANTIC_FALLBACK 并重启；回滚新同步先停 worker，再关闭 MEMORY_SYNC_ENABLED。

现有索引查出 60 个 MySQL 无对应记录的标识，已保留；自动对账默认不删孤儿，召回以 MySQL 门禁拒绝。
人工核对来源和数据库后才可使用 `--prune-orphans`。旧无 TTL 候选及历史 DB 未做全量清除。

复现：`uv run python scripts/benchmark_memory_retrieval.py --execute --split test --threshold 0.5 --components`。
报告写入忽略目录 `data/runtime/memory/retrieval_test.json`，再次运行会覆盖该文件；公共报告仅记录汇总，不包含私有记忆。

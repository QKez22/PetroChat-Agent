# RAG 首版验收与简历说明

## 已交付的能力

- 中文 BM25 与百炼向量检索、等权 RRF、百炼 gte-rerank-v2 重排，支持模式切换及显式降级。
- 精确条款检索与双路检索前置过滤；MySQL 保存版本/权限清单及活动快照，Chroma 新集合完整构建后发布，不覆盖旧索引。
- 按 `[effective_from, effective_to)` 选择版本；未知日期、版本重叠、无权限时不做适用性推断。
- 同版本明确条款引用的一跳补全；LangGraph 最多一次补检；引用 ID、逐字引文、数字和模型支撑性审核。
- Vue 原文证据卡片、适用日期输入、检索/生成/校验阶段提示，原文预览重新鉴权；保留已有 JWT、SSE、Supervisor 和 SQL 链路。

这不是“所有规范均已审核可用”：当前两份 DOCX 的生效日期未核实，只能作为资料参考，不能据此判断现行或历史合规要求。

## 可复现评测结果

语料：2 份 DOCX，1121 个片段；2 份旧 DOC 未转换。原有 110 条标签含占位 ID，仍待重新核对。新增 16 道逐条核对原文的小样本，由开发过程建立，不是独立行业专家标注的权威测试集。12 道开发题、4 道留出题分开，留出结果不用于继续调分词、召回数量或重排参数。

| 数据与后端 | 方案 | Recall@5 | MRR |
| --- | --- | --- | --- |
| 开发 12 题，真实百炼向量的本地精确检索 | 向量 | 10/12 | 0.8333 |
| 同上 | BM25 + 向量 + RRF | 11/12 | 0.8750 |

留出集 P95：向量约 1.51 秒，混合+重排约 3.47 秒；包含真实查询 embedding/HTTP，非缓存查询向量。均为单次、小样本、本机服务测量，不代表稳定线上 P95。重排降级次数为 0。开发集查询 embedding 使用缓存，不能与留出集耗时直接比较。

结论：开发集有改善，留出集召回未改善、排序及耗时反而较差。**不能宣称已证明混合重排总体优于基线，更不能将开发集 100% 写成实际业务准确率。** 默认 RAG_MODE=vector；混合方案保留为显式选项。该默认回退是保守上线决策，不是新的独立测试结果；后续若调参，需补充新的测试集。

原始问题、原文、向量缓存及运行结果位于 ignored 的 data/runtime/rag，不推送远程。

## 本地启用

代码位于隔离 worktree `PetroChat-Agent-rag-evidence`，分支 `codex/rag-evidence`，未合并或改写原项目分支。

1. `uv sync --group dev`。
2. 数据库管理员运行 `scripts/migrations/004_rag_catalog.sql`（本地已执行）。脚本最后两条 GRANT 已授予两张新应用表 CRUD，不授予业务表写权限。
3. 准备显式版本/权限清单并运行 `scripts/publish_rag_snapshot.py`（本地已发布 1121 个片段）。示例命令见执行记录；版本日期不得从文件名猜测。
4. 在此 worktree 的私有 `.env` 设置 `RAG_CATALOG_ENABLED=true`，然后重启 API。此开关默认关闭以兼容未迁移的部署，关闭时不提供文档级版本/权限保证。
5. `RAG_MODE=vector` 为验收后的默认；演示混合重排时显式改成 `hybrid_rerank`。两种模式都可以使用版本策略和证据 QA 子图。
6. 启动 API：`uv run uvicorn petrochat.main:app --host 127.0.0.1 --port 8000`；前端：在 frontend 执行 `pnpm install --frozen-lockfile`、`pnpm dev`。避免覆盖本机已有同端口进程。

聊天接口可传 `rag_as_of: "2024-01-01"`；身份来自 JWT，不由模型决定。当前真实文档日期未知，指定日期应得到无法核实的提示。版本切换逻辑使用明确标为夹具的测试数据验证，尚无真实多版本业务样本证明业务有效性。

## 验证范围与限制

- Python 回归涵盖新 RAG 功能、真实 Chroma 检索、API、预算、任务、语义契约与评测；真实 DeepSeek QA 引文核验和鉴权预览已通过冒烟验证。
- 前端执行锁文件安装、生产构建，以及组件 SSR 测试（文本转义、版本警告和预览按钮语义）；未进行完整浏览器交互/视觉验收。
- 历史消息可从正文恢复证据 ID 并重新查当前可访问快照；尚不保存历史业务日期或提供归档快照回看，原快照不再活动时预览可能返回 404。
- 当前资料是 DOCX，定位到文档、版本、条款和原文；没有虚构 PDF 页码、OCR、bbox 或跨页表格高亮。
- 明确引用仅处理同版本条款号，不包含跨文档自动解析、表格脚注关系、人工关系审核界面。
- 发布工具是管理员 CLI，不开放模型可调用的导入/授权接口；并发导入租约、完整任务恢复、原始文件受控下载尚未实现。
- BM25 目前读取授权快照后在进程内索引缓存，尚未做大规模语料并发压测。
- 逐结论审核针对 QA worker；general 的工具辅助回答不等同于通过该审核。生产可根据需求进一步限制规范问题路由。
- 模型审核不能保证语义正确；不提供虚假的置信概率或无人复核的工业操作建议。
